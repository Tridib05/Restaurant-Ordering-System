# Restaurant Ordering System

A full-stack restaurant ordering system built with Vue.js (frontend) and Node.js/Express (backend) with MySQL database.

## Features

- Browse menu items
- Add items to cart
- Place orders
- Book tables
- User registration and login
- Admin dashboard
- Order tracking

## Tech Stack

- **Frontend**: Vue.js 3, Vue Router, Vuex
- **Backend**: Node.js, Express.js
- **Database**: MySQL
- **Styling**: CSS

## Setup Instructions

See [SETUP.md](./SETUP.md) for detailed setup instructions.

## Quick Start

1. Install dependencies:
   ```bash
   npm run install-all
   ```

2. Set up the database (see SETUP.md for details)

3. Build the frontend:
   ```bash
   npm run build
   ```

4. Start the server:
   ```bash
   npm start
   ```

The application will be available at `http://localhost:8001`

## Development

For development mode:
```bash
# Terminal 1: Start backend
npm run backend

# Terminal 2: Start frontend 
npm run frontend
```
